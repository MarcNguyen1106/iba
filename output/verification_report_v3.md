## Deviations and notes

- The source file stores missing values as the text `NULL` (country 488, agent 16,340, company 112,593) and `NA` (children 4). pandas reads these as NaN. As the brief requires, Raw_Data and Clean_Data hold them as empty cells (129,425 cells). This is the only difference from the source; every other cell matches exactly (see Structure).
- No-deposit Online TA total cancelled = 20,668, confirmed by all three methods.
- Rates are shown as the 1-dp half-up value with the exact per-cent value in brackets. Golden values are given to 2 dp, so a rate passes when the three methods agree at 1 dp and sit within ±0.005 percentage points of the golden figure. One golden value is a rounding tie: Over 365 no-deposit rate = 264 / 1,280 = 20.625% exactly, listed as 20.62% in the brief (half-up would give 20.63%); at 1 dp both are 20.6%, the figure the report quotes.
- Table 1's last row (186) adds four counts; the distinct number of bookings involved is also 186 (no overlap), confirmed by all three methods.
- Table 1 text cells reproduce the report wording with live numbers; the only character difference is a hyphen-minus in "-6.38" where the report uses the typographic minus sign (−).
- Visual QA previews were rendered by LibreOffice (Carlito, metric-compatible with Calibri), whose chart layout differs slightly from Excel's.
- The recalculation time above includes openpyxl's scan of all formulas for error values; LibreOffice itself loads, recalculates and saves the workbook in about 75 s.
- Method C uses the xlsx skill's recalc.py (LibreOffice headless, an explicit calculateAll() and save), which is stricter than a plain --convert-to xlsx because it forces every formula to recalculate.
